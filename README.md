# Microsoft AI-901 Study Guide

## Introduction

Microsoft AI-901 validates foundational knowledge of artificial intelligence and AI solution development on Azure. The current exam emphasizes AI concepts and capabilities plus practical implementation of AI solutions using Microsoft Foundry.

The English-language exam was updated on **April 15, 2026**. Microsoft's current study guide lists the skills measured as of that date. AI-901 has no announced retirement date.

## Who Should Take It?

AI-901 is suitable for:

- Students beginning an AI career.

- Cloud professionals learning AI fundamentals.
- Software developers building introductory AI applications.
- Professionals preparing for Azure AI-focused roles.

## Detailed Study Notes

### Responsible AI

Understand the six major considerations:

**Fairness → Reliability & Safety → Privacy & Security → Inclusiveness → Transparency → Accountability**

Learn how responsible-AI principles influence model selection, deployment, monitoring, and application design.

### Generative AI

Understand:

- Large language models
- Tokens
- Context
- Prompts
- System instructions
- User prompts
- Model parameters
- Multimodal models
- Model deployment
- Grounding
- AI agents

### AI Workloads

Know how to recognize appropriate workloads:

- Generative AI
- Agentic AI
- Text analysis
- Speech
- Computer vision
- Image generation
- Information extraction

### Microsoft Foundry

Learn how Foundry is used to deploy and interact with models, create AI applications and agents, and build lightweight applications with SDKs.

### AI Agents

Understand the basic architecture of an agent:

**User → Agent → Model → Tools/Knowledge → Response**

Study prompts, tools, agent interactions, and basic agent applications.

### Text and Speech

Review:

- Sentiment analysis
- Key phrase extraction
- Entity detection
- Summarization
- Speech recognition
- Speech synthesis
- Multimodal interactions

### Computer Vision

Study:

- Image analysis
- Visual input
- Object recognition
- Image generation
- Multimodal models

### Information Extraction

Understand how Azure Content Understanding can extract useful information from:

- Documents
- Forms
- Images
- Audio
- Video

## Common Mistakes

- Confusing AI, machine learning, generative AI, and agentic AI.
- Memorizing services without understanding their use cases.
- Ignoring responsible-AI principles.
- Confusing speech recognition with speech synthesis.
- Treating computer vision as only image classification.
- Confusing RAG, grounding, and model capabilities.
- Skipping Microsoft Foundry hands-on practice.
- Ignoring Content Understanding.
- Studying outdated objectives without checking Microsoft's current study guide.

## Exam-Day Tips

- Read each scenario carefully.
- Identify the AI workload before selecting a solution.
- Pay attention to requirements involving security, privacy, fairness, and reliability.
- Distinguish between text, speech, vision, generative AI, agentic AI, and information-extraction scenarios.
- For Foundry questions, consider the appropriate model, prompt, SDK, agent, or tool.
- Eliminate options that do not match the stated requirement.
- Review Microsoft's exam sandbox before the exam.
- Manage your exam time carefully.
